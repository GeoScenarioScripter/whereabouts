Date: 2026-10-19 · Issue: #1 · PR: #21 · Verification reached: V1 (local, Windows; CI for Linux)

## API summary (for G1)
| Area | Contract |
|---|---|
| Identity | `VolumeId(u32)` catalog-assigned per registered source. `Frn(u64)` (48-bit record + 16-bit sequence; `record_number()`, `sequence()`). `DatasetId { volume, anchor: Frn }`. `LayerId { dataset, ordinal: u32 }`, ordinal = index in `DatasetMetadata::layers`. |
| Files | `FileRecord { frn, parent, name: FileName, attrs: FileAttributes }`, with `is_dir()` derived from `attrs`. `FileName`: lossless WTF-8; `from_utf16`, `to_utf16`, `as_str() -> Option<&str>`, `as_wtf8()`, `to_string_lossy()`, `from_wtf8()` (validating); `to_os_string()` on Windows. |
| Datasets | `Dataset::new(id, kind, format, members) -> Result` — exactly one `Main` member == `id.anchor`, no duplicate FRNs (also enforced on deserialise); getters + `add_member`/`remove_member`/`members_with`. `Format` (16 variants incl. `Dbf`, `Dwg`, `NameOnly`; `default_kind()`, `is_name_only()`), `DatasetKind` (7), `MemberRole` (16). All enums: `code()`, `from_code()`, `ALL`, `FromStr`, serde = code. |
| Geometry | `Bounds::new(min_x, min_y, max_x, max_y) -> Result` (finite, min ≤ max; degenerate OK); `union`, `intersects`, `width`, `height`. `Wgs84Extent::new(parts)` (≥ 1 part, within ±180/±90), `from_west_south_east_north` (splits when west > east), `parts`, `is_split`, `intersects(&Bounds)`, `intersects_extent(&Wgs84Extent)` (query boxes may cross the antimeridian). Precondition: west > east means a crossing, so only antimeridian-aware producers may pass one. |
| CRS | `CrsDefinition { kind, text, authority: Option<AuthorityCode> }`, `CrsDefinition::epsg(n)`, `epsg_code()`. `CrsDefinitionKind`: `wkt1_esri`, `wkt1`, `wkt2`, `projjson`, `geokeys`, `epsg`. `ResolvedCrs::{Identified { epsg, name }, Unidentified { name }, Unparsed}` + `status()/epsg()/name()`. |
| Reader output | `DatasetMetadata { layers: Vec<LayerMetadata>, partial: Vec<String> }`, `status()` → `Ok`/`Partial`. `LayerMetadata { name, geometry_type, feature_count, crs, native_bounds, fields, raster }`. `GeometryType { kind, has_z, has_m }` ↔ `"MultiPolygon ZM"`. `GeometryKind::parse_lenient` ignores ASCII case, for format-provided names such as GPKG's `'MULTIPOLYGON'`. `RasterInfo { width, height, bands, dtype, res_x, res_y, nodata: Option<String>, overview_count, geotransform }`. `FieldInfo { name, kind, width, precision }`. |
| Reader trait | `FormatReader: Send + Sync { name(), formats(), read(&ResolvedDataset, &ReadLimits) -> Result<DatasetMetadata, ReadError> }`. `ResolvedDataset { format, anchor: PathBuf, sidecars: Vec<ResolvedMember { role, path }> }`. No serde on these: they are in-process only, and serialising a `PathBuf` fails on non-Unicode names. `ReadLimits { max_bytes (16 MiB), time_budget (2 s) }`. `ReadError::{Io, Malformed, MissingMember, Unsupported}` → `status()`. Contract (rustdoc): bounded, read-only, never panic, raw CRS only, deterministic layer order. |
| Catalog unit | `DatasetRecord { dataset, name, primary_path: String, total_size, mtime, status: ExtractionStatus, extracted_at, layers: Vec<LayerRecord { metadata, crs: Option<ResolvedCrs>, wgs84: Option<Wgs84Extent> }> }`. `ExtractionStatus::{Pending, Ok, Partial(r), Unsupported, Error(r)}` + `code()/detail()/from_parts()`. `DatasetRecord::validate()` and `LayerRecord::validate()` check the documented invariants. `ExtractionStatus::from_parts` treats `Some("")` like `None`. `Timestamp(i64)` ns since Unix epoch; `from_system_time`, `from_filetime`. |
| Source | `Source: Send { identity(), root(), enumerate(&mut dyn RecordSink) -> Result<Checkpoint>, changes(&Checkpoint) -> Result<Changes> }`. Checkpoint returned by `enumerate` is taken **before** enumeration (replay covers the gap; consumers apply events idempotently). `Changes::{Batch(ChangeBatch { events, checkpoint }), FullRescanRequired(RescanReason)}`. `SourceEvent::{Created(rec), Deleted(rec), Renamed { record, old_parent, old_name }, Modified(rec)}`. `Checkpoint::new(version, data) -> Result` enforces ≤ 64 KiB, and deserialisation checks the same limit, so `to_bytes`/`from_bytes` (`WBCP` magic) are exact inverses. `SourceError::{AccessDenied, Unsupported, Cancelled, Io}`. |

## Decisions proposed
- **DatasetId = (VolumeId, anchor FRN)**, not a hash or packed `u64`: stable across anchor renames/moves and sidecar churn; delete+recreate of the anchor correctly yields a new dataset; no collisions. The catalog keeps an integer surrogate PK plus `UNIQUE(volume_id, anchor_frn)`. Hard-linked anchors collapse to one ID (documented limitation, matches stage01's hard-link scope).
- **VolumeId is catalog-assigned (`u32`)**, not the NTFS volume serial — serials collide on cloned disks/VHDs and other sources have none. Sources expose `SourceIdentity.key` (NTFS: volume GUID path) for the catalog to match.
- **File names are lossless WTF-8 (`FileName`)**: identical to UTF-8 for valid names (zero-cost `as_str`), preserves unpaired UTF-16 surrogates so every file stays openable; bytes go straight into the name-index pool. Serde: string, or UTF-16 array for invalid names (human-readable); WTF-8 bytes (binary).
- **`LayerId.ordinal` = reader order**; readers must order layers deterministically; layers are replaced wholesale on re-extraction.
- **Enum codes are frozen strings** (`code_enum!`): catalog TEXT values and serde forms are the same and never change once released. Geometry/raster/field type names follow OGC WKT / GDAL / OGR spelling to simplify oracle comparison.
- **`Timestamp` = i64 ns since Unix epoch** (exact for NTFS 100 ns times; 1677–2262).
- **`ReadLimits` defaults**: 16 MiB per dataset, 2 s — starting values for 3.3/4.3 to tune.

## Deviations / contract changes (vs. the 1.1 spec wording)
- `FullRescanRequired` is **not** a `SourceEvent` variant: `Source::changes` returns `Changes::{Batch, FullRescanRequired(RescanReason)}`. A rescan can then never be committed together with a checkpoint, and event consumers (nameindex, grouper) don't have to handle a non-event. `Deleted` and `Modified` carry the full `FileRecord`.
- `Source` also has `identity()` and `root()` (needed for volume registration and path reconstruction).
- `Dataset` stores `id: DatasetId` (which contains volume + anchor) with `volume()`/`anchor()` getters instead of separate `volume`/`anchor` fields; fields are private to keep the member invariants.
- `CrsDefinition` gained `authority: Option<AuthorityCode>` (GPKG `organization`/`organization_coordsys_id` beside WKT without `AUTHORITY`).
- `ResolvedDataset` names non-anchor members `sidecars` (the anchor is its own field), and it has no serde derives.
- `FileRecord` has no `is_dir` field (the spec listed one). Use `is_dir()`, which reads `FileAttributes::DIRECTORY`, so there is only one source of truth.
- Extra types beyond the list: `ResolvedCrs`/`CrsStatus`, `LayerRecord`/`DatasetRecord`, `Timestamp`, `ReadLimits`, `FieldInfo`/`FieldKind`, `GeometryKind`, `RasterDataType`, `AuthorityCode` — needed so every catalog column maps to a field.
- `Format` adds `Dbf` (lone `.dbf` → non-spatial table, per 2.3) and `Dwg` (name-only, kind `cad`) next to `NameOnly`; `DatasetKind` adds `table` and `unknown` to the sketch's five.
- Size: ~1,350 non-blank, non-comment code lines + ~820 test lines + rustdoc — above the ≲ 1,500 guideline, because contracts are doc-heavy.
